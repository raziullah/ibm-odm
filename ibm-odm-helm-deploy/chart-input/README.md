The Publish stage downloads `ibm-odm-prod` chart version `26.0.3` from IBM's public Helm repository into this directory. The pipeline then unpacks the chart and pushes its contents under `ibm-odm/chart/ibm-odm-prod` in CodeCommit. The Azure agent needs Helm and internet access to the IBM chart repository. Access to the ODM container images still requires the applicable IBM entitlement.
